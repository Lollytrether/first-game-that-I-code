# first-game-that-I-code
I'm following a Udemy course on building a 3d game in Godot. I was using Maya to model, but due to compatibility issues, I am now using Godot. Note some of the textures I have are not made by me, I downloaded a bunch like 10 years ago and the only thing they had were the textures themselves. Built on Godot script, it runs on windows, I would port it to web but am unsure how to. 

Controls:
Arrow keys to move
CTRL + Arrow keys to aim
Space bar to fire
