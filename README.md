# first-game-that-I-code
I'm following a course on building a 3d game in Godot. I was using Maya to model, but due to compatibility issues, I am now using Godot. Note some of the textures I have are not made by me, I downloaded a bunch like 10 years ago and the only thing they had were the textures themselves. Built on Godot script, it runs on windows, I would port it to web but am unsure how to. 

First week:
Modelled the Tank, bullet, and the hills, used the physics engine, figured out/googled a few nodes for all objects, debugged the bullet falling through the ground (collision/mask layers). Implementing the physics engine was pretty easy, just node stuff that I don't remember too well. Collision layers were difficult, spent most of the time on that, I forgot to comment the code so it'll still take me a minute to figure it all out. The scripts folder is mostly used for debugging which is why it might work.

Second week:
Enemies are sill buggy, most of the time was spent on pathfinding, the game files corrupted but I remembered the systems needed.

Controls:
Arrow keys to move
CTRL + Arrow keys to aim
Space bar to fire
